# 任务提示包：示例项目-全量

> 导出自 memory-porter 记忆库（demo-web-app + common），日期 2026-09-29。
> 用法：新任务开场说「读取并遵循 <本文件绝对路径>」即可，无需调用任何技能。

**【给读取本文件的 Agent】**：把下方「约定清单」全部当作本轮任务的固定规则，从第一个动作起直接遵循；不要等待用户复述，不要修改本文件，除非用户明确要求更新。

## 约定清单

### 沟通与协作偏好（通用，applies: 所有协作场景）

- 用中文回复，分步骤，给可直接粘贴的代码或命令。
- 动手改之前先用两三句话说清方案，得到认可再执行（一句话能改的不算）。
- 涉及生产环境/线上数据的操作，先提示风险并确认。
- 报告结果时给出真实执行输出，不编造「应该没问题」。

### 提交与代码风格（来源项目：demo-web-app，applies: 所有写代码、提交代码的任务）

- 包管理器用 pnpm，不用 npm/npx。
- TypeScript 开 strict；禁止 any，必要时用 unknown + 类型收窄。
- 提交信息中文，格式 `<type>: <摘要>`，type ∈ feat/fix/docs/refactor/test。
- 提交前必须通过 `pnpm lint && pnpm test`，失败不许提交。
